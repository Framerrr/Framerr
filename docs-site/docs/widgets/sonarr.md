# Sonarr Library

Displays your Sonarr TV show library with upcoming and missing episodes from your library.

## Supported Integrations

| Integration | Features |
|-------------|----------|
| [Sonarr](/docs/integrations/sonarr) | Series list, missing episodes, queue, stats |

## Configuration Options

| Option | Default | Description |
|--------|---------|-------------|
| View Mode | Auto | **Auto** — adapts layout to widget size. **Stacked** — sections stacked vertically. **Column** — sections in columns side by side. |
| Summary Bar | Show | Show or hide the statistics bar at the top (series count, episode count, etc.) |
| Look Ahead | 30d | How far ahead to show upcoming episodes (`7d` / `30d` / `90d` / `All`) |
| Show Network | On | Show network badges on episode rows |
| Season Progress | On | Show season progress on upcoming items |
| Highlight Premieres | On | Emphasize premiere episodes |
| Needs Attention | Missing + Upgrades | Toggle visibility of missing and cutoff-unmet groups independently |
