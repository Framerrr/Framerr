# Lidarr Library

Displays your Lidarr music library with upcoming and missing albums from your collection.

## Supported Integrations

| Integration | Features |
|-------------|----------|
| [Lidarr](/docs/integrations/lidarr) | Upcoming albums, missing/cutoff albums, queue, stats |

## Configuration Options

| Option | Default | Description |
|--------|---------|-------------|
| View Mode | Auto | **Auto** — adapts layout to widget size. **Stacked** — sections stacked vertically. **Column** — sections in columns side by side. |
| Summary Bar | Show | Show or hide the statistics bar at the top (upcoming, missing, upgrades, downloads) |
| Look Ahead | 30d | How far ahead to show upcoming album releases (`7d` / `30d` / `90d` / `All`) |
| Show Album Type | On | Show album-type badges next to release dates |
| Needs Attention | Missing + Upgrades | Toggle visibility of missing and cutoff-unmet album groups independently |
