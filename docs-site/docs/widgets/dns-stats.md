# DNS Stats

Shows DNS filtering stats from AdGuard Home or Pi-hole — query totals, blocked percentage, latency, activity over time, and top lists.

## Supported Integrations

| Integration | Features |
|-------------|----------|
| [AdGuard Home](/docs/integrations/adguard) | Stats strip, sparkline, top lists, protection toggle |
| [Pi-hole](/docs/integrations/pihole) | Stats strip, sparkline, top lists, protection toggle (v5 and v6) |

## Configuration Options

| Option | Default | Description |
|--------|---------|-------------|
| Top Blocked | On | Show the top blocked domains list |
| Top Clients | On | Show the top client list |
| Activity | On | Show the query/blocked sparkline |
| Top Queried | On | Show the top queried domains list |
| Top Upstreams | On | Show the top upstream resolvers list |
