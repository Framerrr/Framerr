# Prowlarr

Monitors indexer health and recent activity from your Prowlarr instance.

## Supported Integrations

| Integration | Features |
|-------------|----------|
| [Prowlarr](/docs/integrations/prowlarr) | Indexer health, applications strip, recent activity, health messages |

## Configuration Options

| Option | Default | Description |
|--------|---------|-------------|
| Summary Bar | Show | Show or hide the top summary chips (total / enabled / healthy / failing / disabled) |
| Applications | Show | Show or hide the connected applications strip |
