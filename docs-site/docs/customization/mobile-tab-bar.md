# Mobile Tab Bar

On phones and tablets, Framerr’s main navigation is the tab bar along the bottom of the
screen. You can customize this bar, add shortcuts, and put specific dashboards
within easy reach.

Configure it in **Settings → Customization → Mobile Tab Bar**.

## Editing

The settings page shows a live preview of the bar. Tap a button to select it,
then move it, change what it opens, or remove it. Changes save as you go.

You can have up to five buttons. **Menu**, **Settings**, and at least one
**Dashboard** always stay on the bar.

## Dashboard buttons

A dashboard button opens that dashboard. If you have more than one, you can add
extra dashboard buttons — each pointed at a different dashboard — so your most
used layouts are one tap away.

Press and hold any dashboard button to switch between dashboards or create a
new one. See [Dashboard](../features/dashboard#switching-dashboards).

## Shortcuts

Besides Menu, Settings, and dashboards, you can add:

- **Profile** — open your profile settings
- **Notifications** — open the notification center
- **My Tab** — pin a sidebar iframe tab from Settings → My Tabs; its label and icon stay
  in sync with My Tabs. Counts toward the same five-button limit.

## Reset

**Reset** restores the default layout: Menu, your Home dashboard, Profile, and
Settings.
